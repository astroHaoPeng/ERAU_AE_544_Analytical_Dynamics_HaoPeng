## Detailed Steps

1. Install `Obsidian`
2. Get the GitHub education package.
3. Install `GitKraken` and clone the repo.
4. Open the cloned folder as a vault in Obsidian, and you should have all the plugins and configurations set up correct. If not, you may have opened a child folder instead of the root folder.


## Q&As

### Why GitKraken? 
With GitKraken, you will be able to merge your local changes (if any) to notes and my changes to the notes in an easier manner.
**PDF files cannot be merged as they are binary files.**

GitKraken Pro is available once you registered GitHub Education Package. Check my lab tutorial above.

### What is `.gitignore`

Only source codes for the lecture notes are needed to be distributed. 

Files like compiled PDF lecture notes or homework solutions are not suitable for distribution. 

Using a `.gitignore` file can control what files to be tracked by `git`. Learn more by yourself if needed.
